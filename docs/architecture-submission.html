承認済み候補の並べ替え・強調のみ。危険度は下げられない

リプレイも本物の処理経路

演習・リプレイが差し替えるのはイベント入力と時刻だけ。根拠の検証・計画・Safety Core は本番と同じコードを通る

再接続の照合ゲート

RECONNECTING → 根拠の再取得 → 照合 → 必要なら再計画 → ONLINE_VERIFIED。再接続だけでは「最新」に戻さない

説明可能性

計画の失効理由・参照した根拠 ID を構造化トレースで公開。AI の内部推論は出さない
