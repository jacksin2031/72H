# 動作確認の方法

ログイン・テストアカウント・アクセスキーは不要です。スマートフォン幅、またはブラウザの幅を狭めた状態での確認を推奨します。初期表示は日本語です。

## 1. まずは「3.11体験」で目的を確認

https://h72-vux6j7xjka-an.a.run.app/judge を開き、「3.11体験を始める」を押してください。

宮城県石巻市にいる、土地勘のない旅行者という演習設定です。東日本大震災の歴史記録を模擬入力として、14:46の地震、14:49の大津波警報、15:14の警報更新、15:15の余震を順に処理します。人物・位置は演習用の仮定であり、当時の現地状況を完全再現するものではありません。

開始時に最初の出来事を処理します。その後は「次の出来事へ」で残りの出来事を進めてください。歴史上の待ち時間は省略しますが、AIの処理には数秒から十数秒かかる場合があります。

各画面に表示される行動と「この行動の理由」を確認し、「根拠」を開いて情報源を確認してください。新しい情報に応じて、72Hが計画や根拠を更新する様子を確認できます。計画が維持される場合もあり、イベント数と計画数は必ずしも一致しません。

## 2. 実際の処理結果とAI実行を確認

4件の出来事の処理後、「体験を振り返る」を押してください。作成された計画の履歴、評価した出来事、Gemini / ADKの実行結果が表示されます。

「実行成功」は、その回に実際に成功したGemini / ADK処理の件数です。AI応答が無効・時間切れなどの場合は、決定論的な安全規則にフォールバックし、その件数を別に表示します。AIは所在地に応じた演習判断を補助しますが、実際の移動を許可するものではありません。

## 3. 断線・再接続・未確認情報を追加確認（任意）

https://h72-vux6j7xjka-an.a.run.app/demo を開き、「Tokyo Earthquake Replay」を選び、「デモを開始」を押してください。

「次の更新 →」で合計11件のイベントを進めると、交通情報の変化による計画の失効と再計画、未確認SNS投稿の行動根拠からの除外、通信断時のオフライン継続、再接続後の根拠の再取得・照合を確認できます。通信断は演習イベントとして再現されます。

## 4. 表示言語

3.11体験では、開始前の「表示言語」で日本語 / English / 繁體中文 / 简体中文を選べます。通常画面では「その他 → 言語」から切り替えられます。言語が変わっても、安全判定の規則と根拠は共通です。

## 注意事項

- 演習の情報は歴史記録を基にした模擬入力・合成データです。実際の現在の災害情報ではありません。
- 72Hは公式の避難指示に代わるものではありません。経路が利用可能でも安全の証明ではなく、実際の移動許可は出しません。
- 混雑時は少し待ってから再実行してください。処理結果を確認できない旨が表示された場合は、「最初からやり直す」で再開してください。
- OSS・オープンデータのライセンス情報は、リポジトリ直下の `THIRD_PARTY_NOTICES.md` に記載しています。
