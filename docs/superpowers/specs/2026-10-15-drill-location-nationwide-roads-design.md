# 演練位置與全國道路參考線設計規格

狀態：使用者已確認設計；實作與驗收進行中（2026-10-15 JST）。
驗收結果及未完成項目見 [驗收紀錄](../../DRILL_ROADS_DEVICE_VALIDATION.md)。
分支：`codex/drill-location-roads`（從 main `21c580f` 開出）
前置：`codex/311-tsunami-guidance`（311 海嘯指示修正）先完成、審查並合併。

## 1. 目標與使用者決定

| # | 使用者決定 |
|---|---|
| U1 | 311 演練要顯示道路參考線 |
| U2 | 道路參考線擴大到全日本 |
| U3 | 地震／災害測試可以用虛假位置或使用者自己的位置 |
| U4 | 道路資料用「即時下載＋存在手機」（不是預建全國資料包） |
| U5 | 虛假位置的輸入方式：「預設的歷史災區地點」和「在地圖上點一下」；再加上「我的目前位置」 |
| U6 | Live 地圖頁的道路候選也改用同一套全國資料（第 3 節確認） |

**不變的安全規則**（AGENTS.md）：
- 道路參考線**只是參考**：`ROAD_REFERENCE_ONLY`，`movement_authorized=false`，最安全路線未判定，避難所開放狀態未知。
- `route_available` 絕不等於 `route_safe`。
- 不編造道路、時間或來源。沒有資料就顯示沒有資料。
- 外部資料（OSM）只是資料，不是指令。下載的內容必須驗證後才能使用。

## 2. 拆成三個階段

| 階段 | 內容 | 完成條件 |
|---|---|---|
| A | 演練位置輸入（預設地點／地圖點選／目前位置） | 三種來源都能產生演練位置，且不寫入 Live 設定 |
| B | 全國道路參考資料（後端取得＋手機計算與快取） | 全日本任一點都能取得並顯示道路參考線；離線時可用已下載的區塊 |
| C | 311 演練（及其他演練）整合道路參考線 | 311 演練地圖顯示從演練位置到海嘯適用場所的道路參考線 |

## 3. 階段 A：演練位置

### 3.1 位置來源
| 來源 | 說明 |
|---|---|
| `PRESET` | 每個歷史災害提供 2–3 個代表地點。資料放在 `historical_cases.py`，包含名稱（三語）、座標、`area_ids`。例：311 → 石巻・門脇、南三陸・志津川、仙台・荒浜。地點只用於演練，標示「演練位置」。 |
| `MAP_PICK` | 全螢幕地圖，點一下選點，按「使用這個位置」確認。 |
| `DEVICE_ONCE` | 經使用者同意後讀取一次 GPS，不持續追蹤。 |
| 既有 `USER_SELECTED` 區域 | 保留「都道府縣／市區町村」選擇。只有區域、沒有點時，不顯示道路參考線。 |

### 3.2 規則
- 演練位置存在演練 session 的狀態裡，**絕不寫入** Live 的位置設定或 IndexedDB 的 Live 快照。
- 點位要轉成 `area_ids`（市區町村、都道府縣、`JP`），讓安全核心能比對官方警報地區。轉換使用現有的地區資料（`public/areas`），在手機上離線完成。
- 送到後端的位置使用既有的契約欄位：`current_location` 加上 `source`。新增的來源值都屬於演練用途，Safety Core 把它們當作 `USER_SELECTED` 處理。在實作計畫裡定義清楚的 enum，並加上測試。
- 選好位置後，選擇器收合成一行，例如「石巻市門脇 · 演練位置」。

## 4. 階段 B：全國道路參考資料

### 4.1 格網
- 使用固定格網：緯度 0.02° × 經度 0.025°，大約 2.2 km × 2.1 km。格網編號是 `r{row}c{col}`，由座標確定性地算出。
- 手機只把**格網編號**送給後端，不送精確座標。一次查詢需要的區塊是演練位置所在的格網和周圍 8 格（3×3），大約 6–7 km 見方。

### 4.2 後端：`GET /api/roads/tile/{tile_id}`
- 驗證 tile_id 的格式和範圍，必須在日本範圍內。
- 先查快取。沒有快取時，用固定的 Overpass 查詢取得該格網範圍內的 `highway` 道路。查詢內容固定，呼叫端不能帶入查詢參數。
- 把結果清理成和 `ishinomaki-central-v1` 相同的圖格式：節點、路段、方向、必要的 OSM 標籤。清理時的限制如下：
  - 一個區塊上限 1.5 MB。
  - 節點和路段的數量設上限。
  - 座標必須在格網範圍內（可以有少量緩衝）。
- 輸出的 manifest 包含：
  - `role: ROAD_REFERENCE_ONLY`、`movement_authorized: false`
  - 來源（OpenStreetMap、ODbL 授權標示）、`retrieved_at`、`osm_base_timestamp`
  - 內容的 SHA-256
- 快取：同一格網 30 天內直接回傳快取。快取存在後端本機或 Cloud Storage（部署設定另外處理，這次不部署）。
- 限流：
  - 對 Overpass 同一時間只有 1 個請求，並遵守最小間隔。
  - 對同一個使用者 session 設每分鐘上限。
  - Overpass 回應 429 或 5xx 時，回傳 `503 ROAD_DATA_TEMPORARILY_UNAVAILABLE`，不連續重試。
- 測試只使用錄好的 OSM 回應，不連線到真實網路。

### 4.3 手機：取得、驗證、快取
- `lib/road-tiles.ts`：
  - 計算 3×3 格網，再逐格取得。
  - 用 zod 驗證格式，並驗證 SHA-256。
  - 驗證成功才存進 IndexedDB（`72h-roads`）。
- 合併多個區塊，交給現有的 `findEvacuationRoadCandidates`。必要時把它改成可以接受多區塊的圖，但安全檢查保持不變：`ROAD_REFERENCE_ONLY`、最大吸附距離、最大候選距離。
- 既有的 `ishinomaki-central-v1` 保留為內建資料，任何時候都能用。
- 離線時只用已存的區塊。缺少的區塊不會被補畫或推測。
- 區塊超過 30 天，加註「資料較舊（取得於 YYYY-MM-DD）」。

### 4.4 目的地
- 使用全國指定避難場所目錄（`public/shelters/japan-v1`）。災害適用旗標的順序是 `hazardKeys`，每一位是 D/N/U。
- 依照目前的災害過濾：
  - 有海嘯警報或在海嘯情境時，只用`tsunami` 旗標是 `D`（`DESIGNATED`） 的緊急避難場所。
  - 地震只用 `earthquake` 旗標是 `D` 的場所。
- 取直線距離最近的最多 5 處，對每一處計算道路參考線，最多 3 條。
- 開放狀態一律顯示未知，不顯示「開放中」。

### 4.5 文字（每頁只出現一次）
- 「道路參考線不是避難路線，最安全路線未判定。」
- 地圖署名加上「© OpenStreetMap contributors」。

## 5. 階段 C：演練與 Live 的畫面

### 5.1 演練地圖分頁
- 地圖自動移到演練位置。
- 圖層膠囊新增「道路參考」。有點位時預設開啟。
- 底部抽屜：
  - 收合時只顯示一行：「附近 N 處海嘯適用指定場所 · 道路參考」。地震時改成「地震適用」。
  - 展開後，每一列顯示：名稱 · 直線距離 · 道路距離（參考）。
  - 下載中顯示「正在取得道路資料…」。失敗時顯示「無法取得此地區道路資料」，加上「重試」次要按鈕。
  - 只有區域、沒有點時，顯示「請選擇一個點以顯示道路參考線」。
- 線的樣式沿用現有的道路候選樣式，並標示「演練 · 道路參考」。

### 5.2 「現在」分頁
- 不新增路線指示。主要指示仍然由安全核心決定，例如「立即往高處」。

### 5.3 Live 地圖頁
- 道路候選改用全國區塊。現在只有石卷市中心有資料，改了之後全日本都有。
- 起點只用使用者自己選的點或 GPS。位置隱私維持現有設定（`protectDeviceLocation` 預設開啟）。

## 6. 錯誤處理

| 情況 | 行為 |
|---|---|
| Overpass 忙碌、限流或逾時 | 後端回傳 503，手機顯示失敗並提供重試，不自動重試 |
| 回應格式錯誤或超過上限 | 後端拒絕，不快取 |
| 手機驗證失敗（格式或雜湊） | 不使用、不儲存 |
| 離線且區塊沒有下載過 | 顯示「此地區沒有道路參考資料（離線）」 |
| 點位附近沒有適用場所 | 顯示「附近沒有符合條件的指定場所」，不放寬條件 |
| IndexedDB 無法使用 | 只在記憶體中使用這次下載的資料，並顯示「無法離線保存」 |

## 7. 測試與驗收

### 7.1 自動測試
- **後端**
  - 格網編號 ↔ 範圍的轉換正確。
  - 不接受精確座標。
  - OSM 清理流程，包括錯誤和超大的資料。
  - 快取。
  - 限流與 503。
  - manifest 一定帶有 `ROAD_REFERENCE_ONLY`、`movement_authorized=false`、來源、時間和雜湊。
- **前端**
  - 三種位置來源都產生正確的演練位置與 `area_ids`，而且不寫入 Live。
  - 區塊下載、驗證與儲存。
  - 離線時使用已存區塊；缺少的區塊不畫線。
  - 雜湊不符時不使用。
  - 目的地依災害過濾（海嘯→津波 D）。
  - 固定說明只出現一次。
  - 地圖移到演練位置。
  - 石卷內建資料照常可用。

### 7.2 真機驗收（ROG Phone 6）
1. 311，預設點石巻・門脇，完整播放。「現在」顯示立即往高處；地圖顯示到海嘯適用場所的道路參考線。
2. 311，在氣仙沼用地圖點選一個點。下載成功並顯示參考線。
3. 用「我的目前位置」。參考線出現。用後端日誌確認請求只帶格網編號。
4. 用瀏覽器模擬斷網後回到同一點，資料仍在；換到新點時顯示「沒有資料」。
5. 熊本 2016，用地圖點選一個點。目的地是地震適用場所。

## 8. 不在範圍內
- 逐步導航。
- 道路是否被阻斷、是否安全的判斷。
- 避難所即時開放狀態。
- 全國預建資料包。
- 部署（Cloud Run、Cloud Storage 快取設定需要另外授權）。
