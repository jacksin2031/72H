# P2.7 解釋及按災害分類避難路線 — 本地設計

使用者已要求實作 AI 行動解釋及最安全路線，並指定優先按災害類別選擇指定避難地點。範圍為本地實作及驗收，沒有部署。

## AI 解釋

LIVE／REPLAY 計劃一律先經決定性 Safety Core；停止模型在最後 gating 前選擇行動的入口。模型只接收當前批准的 action／fact／evidence IDs、限制、語言與版本。Gemini／ADK 輸出白名單解釋條款及依據選擇，程式以三語語句呈現；不发布無法核對的自由文字。逐次版本、期限、網絡及證據核對，遲到或錯誤輸出降級。歷史計劃、TTL、目的地及移動授權不受解釋影響。模擬位置評估保留独立演習契約。

提供 POST `/api/live/{id}/explanation`、`/api/replay/{id}/explanation` 及受演習密鑰保護的 `/api/mock-live/{id}/explanation`。輸出包含 plan_id、plan_version、binding hash、mode、expires_at、language、已核對段落與限制。讀取後再次核對現有快照，防止模型回覆期間改版。沒有計劃亦顯示保守固定說明。主頁及 Plan／模擬 Plan 接入同一元件，離線使用決定性模板。

## 路線

重用石卷官方指定場所目錄／八類災害及自治體開放 adapter。只有 `EMERGENCY_SITE` 且該災害 `DESIGNATED` 列作指定用途候選；一般 SHELTER 不互換。官方分類不代表當前安全。

限定石卷小區域道路候選試點：有來源與 hash 的公開路網固定資產，於裝置本地計算，不上傳精確 GPS。道路圖不證明災後通行。路徑必須沿圖內道路，未連通、覆蓋外或接駁缺失明示；不可用直線冒充道路。全國尚未覆蓋處顯示路網未配置。

UI 在公共參考地圖提供災害分類、指定場所、本地起點、候選道路及核實清單；Plan 提供入口。不啟用導航、不擴大 consumer 地圖掛載／movement gates。所有現有開放、路況、動態災害覆蓋及移動授權不足時顯示「最安全路線未判定」，列出原因；不按距離假稱最安全。候選顯示距離僅作道路資料比較。

## 驗收

解釋：真實 Gemini／ADK、三語、注入及杜撰 IDs、缺限制、舊版本／取消／逾時／離線、計劃不變、候選 planner 不再影響 LIVE／REPLAY 行動。
路線：災害／角色隔離、道路路徑連通與邊界、未知／過時開放、錯誤座標／graph、無道路候選、圖層不足不升級安全、GPS 不發送。後端／前端 tests、typecheck/build、secret scan 及實際瀏覽器。

完成狀態須分開：AI 解釋本地功能、道路候選試點、真實最安全路線、全國覆蓋及部署。沒有官方即時路況及開放等證據，真實最安全路線保持 PARTIAL／未判定。
